The Opportunity

As spatial computing becomes more prevalent, traditional 2D UI paradigms are failing. This project was initiated to explore how generative AI could assemble user interfaces on the fly in a 3D environment, adapting to the user's physical context and immediate intent.

The Approach

Instead of designing static screens, I designed a system of rules and atomic components. The AI acts as the layout engine, pulling from this design system to construct interfaces in real-time. The visual language relies heavily on glassmorphism and depth to establish hierarchy in Z-space.

Outcomes & Learnings

The prototype successfully demonstrated that AI-driven layout engines can reduce cognitive load by only presenting necessary controls. However, establishing predictable interaction patterns remains a challenge when the UI is highly fluid.
