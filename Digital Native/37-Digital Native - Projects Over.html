The Problem Space

Traditional state management in React often leads to prop drilling or overly complex context structures when dealing with highly dynamic, deeply nested 3D scenes. I wanted to explore if a signals-based approach could provide more deterministic updates for WebGL rendering cycles.

Research & Approach

I built a prototype using Preact Signals integrated into a React Three Fiber setup. The goal was to bypass React's reconciliation phase entirely for high-frequency updates (like camera position or object rotation). 

import { useSignal } from '@preact/signals-react';
import { useFrame } from '@react-three/fiber';

const RotatingCube = () => {
  const rotation = useSignal(0);
  
  // Bypasses React render phase
  useFrame(() => {
    rotation.value += 0.01;
  });

  return (
    <mesh rotation-y={rotation}>
      <boxGeometry />
      <meshStandardMaterial color="#FF6600" />
    </mesh>
  );
};

Outcomes & Lessons

The signals approach resulted in a consistent 60fps even with 10,000+ independently updating meshes, where standard React state caused severe frame drops due to reconciliation overhead.

  • Achieved O(1) update complexity for deeply nested 3D objects.
  • Reduced memory allocation during render loops by 40%.
  • Identified edge cases with React DevTools integration.
